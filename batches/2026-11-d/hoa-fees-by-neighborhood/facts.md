Method and rerun: the data folder's README.md.

Source of every count: the site's public map API, `https://chapter3realty.com/homes/api/map` (Coastal Carolinas MLS listings through the CRM, the same search the site's Homes page uses), and the public listing card, `https://chapter3realty.com/homes/api/lookup?mls=<n>` (the subdivision name). The per-home working cache (MLS numbers) is in the scratchpad (`hoa-nbhd-cache-2/`), never in the website repo. No MLS number, address, listing firm or photo is saved in the data folder or printed.

How a fee is measured: the API returns no fee on a pin. It filters by the site's own "HOA up to $X a month" box (`hoaMax`). For each community and kind of home, each home's fee is narrowed by halving over the steps $0, $10 ... $600, $650 ... $1,500, $2,000, $3,000, until each home sits in one step; refine_exact.py then halves inside the step to the dollar ($141 ... $150), so each fee is the listing's monthly fee in whole dollars. `hoaMax=0` returns homes whose listing gives no fee or $0; `hoa=0` returns the homes whose listing says there is no HOA. A community is the exact MLS subdivision name (case and spaces folded). The subdivision search matches words, so the counts keep only homes whose own card has that exact name.

The pull ran 2026-11-13, 20:26 to 21:42 UTC; every fee was measured before 21:30 UTC, when the API began to answer 503 "stale" (README.md, Limits). CACHE: scratchpad `hoa-nbhd-cache-2/`. The fee in rows 1 to 29 is in whole dollars (refine_exact.py) except Edgefield and Waterfall ($10 step top).

API for every count row: https://chapter3realty.com/homes/api/map (a sample query is given per row; replace the name to check another).
