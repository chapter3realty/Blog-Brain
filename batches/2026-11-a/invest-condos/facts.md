# Fact ledger: /invest/condos/

Batch 2026-11-a, Lane U. Researcher: research helper, 2026-11-02. **The writer may use rows marked `verified` only.** Columns 9 and 10 are for a verifier who did none of this research. Rows reused from a sibling ledger keep that ledger's status and say so.

Raw files, the scripts that pulled them and the script that computes every derived number are in the website working copy at `data/2026-11-a/invest-condos/` (see its `README.md`):
- `pull-suggestions.sh` (Google suggestions); `zhvi_compare.py` (Zillow, writes `zhvi-compare.json`); `count_ratio.py` (four county count queries, `raw/ratio-counts.json`); `fetch_condo_parcels.py` and `fetch_flood.py` (county GIS, raw kept in scratch); `analyze.py` (writes `findings.json`); `pull_listings.py` (CRM map API, aggregate counts only, writes `listings.json` with every URL called).
- `raw/` holds text copies of the statutes, the 2026 levy, Fannie Mae's page, the ACS tables and the Zillow rows.

**Never on the page, from any row:** an interest rate, a loan payment, a down payment percentage, any address, PIN or owner, a value for any one address or listing (no AVM). The worked example is built from medians of many listings, never one listing. Sold prices come from county deed records, never the MLS. No building is named with a conclusion about it.

Short names for sources:
- **ZHVI**: Zillow Research, Home Value Index, metro files, mid tier (33rd to 67th percentile), smoothed, seasonally adjusted, region "Myrtle Beach, SC" (RegionID 394898, RegionType msa). Condo: https://files.zillowstatic.com/research/public_csvs/zhvi/Metro_zhvi_uc_condo_tier_0.33_0.67_sm_sa_month.csv ; houses: same with `sfr`. Data page: https://www.zillow.com/research/data/ (series "ZHVI Condo/Co-op Time Series" and "ZHVI Single-Family Homes Time Series"). Extract `raw/zhvi-metro-condo_tier_0.33_0.67-mb.csv`, `raw/zhvi-metro-sfr_tier_0.33_0.67-mb.csv`; derived `zhvi-compare.json`.
- **Parcels**: Horry County GIS parcel layer 24, https://www.horrycounty.org/parcelapp/rest/services/HorryCountyGISApp/MapServer/24 , read 2026-11-02. Condo unit = residential land use (1xx), building value above 0, legal description containing "HPR". Fields AssessedProp, TaxableProp, MarketProp, OwnerState, TaxDistrict, LegalDescr. Count URLs in `raw/ratio-counts.json`.
- **Deeds**: Horry County AcclaimWeb DEED (001) index, home sales recorded 2025-10-01 to 2026-09-30, from batch 2026-10-d's pull and filters (`data/2026-10-d/sell-out-of-state-buyers/out-of-state-buyers.json`, 13,194 kept home sales; deed consideration = price), joined to Parcels. Output `findings.json` key `sales`.
- **Flood**: Horry County GIS layer 19 "Flood Zones" (FEMA flood map polygons: VE 42, AE 711, A 5, shaded 0.2 percent 1,322; no zone X polygons), https://www.horrycounty.org/parcelapp/rest/services/HorryCountyGISApp/MapServer/19 , point query at each sale's parcel center point. Output `findings.json` key `flood_condo_sales`.
- **CRM**: the site's public map API, https://chapter3realty.com/homes/api/map?<params>, `has=county_horry` on every call, counted in aggregate. Pulled 2026-11-02 11:20Z (`listings.json`, 273 calls). MLS source line: "Coastal Carolinas Association of REALTORS® Multiple Listing Service (CCMLS)". `hoaMax` is the site's "Up to $X a month" filter; every Horry condo for sale has a fee above $0 (`hoaMin=1` returns all 2,656). Listing flags (`str_allowed`, `fha_accepted` and the rest) are what the listing says, not a lender's or the city's decision.
