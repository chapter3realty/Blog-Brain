## Deciding fact (checked first)

Can the page give a rent for a house by bedrooms and by named area from public sources, without MLS lease data? **Yes.** ACS5 B25031 gives the middle rent by bedrooms for Horry County and for each named place, including the unincorporated areas readers search by name (Carolina Forest, Socastee, Murrells Inlet, Garden City, Little River, Red Hill are census-designated places). PUMS separates houses from apartments and new leases from old ones, which no published table does. ZORI gives the current asking rent for houses in the metro. The CRM map API carries no lease listings (the site's search types are house, condo, townhouse, manufactured, multi and land; a `type=lease` query returns the same 8,762 for-sale homes as no type), so no rent comes from it.
