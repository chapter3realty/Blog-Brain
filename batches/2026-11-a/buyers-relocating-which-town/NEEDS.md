# Needs: /buyers/relocating/which-town/

1. **One group for "the middle house" across the site (lead decides).** This page uses detached houses only, the /invest/where-to-buy/ group (its row 16). /buyers/cost-to-own/ and /sell/home-value/ use "every residential parcel that is not a condo" (houses, townhouses and manufactured homes), so their middle price and yearly cost for the same town differ (Carolina Forest: $440,000 and about $8,480 here; $395,000 and about $8,310 there). Both are labelled, but a reader comparing pages sees two numbers. Either label every surface or pick one group sitewide.
2. **A fault in the CRM band pull, sibling scripts.** When a price band has no match, the map API returns suggested homes that do not match the filter (total 0, pins > 0). `data/2026-11-a/invest-where-to-buy/pull_listings.py` (and any copy of its `band()` function) counts those. Fix: skip a band whose total is 0, as `pull_features.py` here now does. WTB row 14's verifier re-pulled and matched, so the effect there may be small; the "has" sets with few matches (str_allowed) are the ones at risk.
3. **A several-places map.** `tools/area-map.js` draws one community; this page needs 13 numbered outlines with the county line (where-to-buy drew its own). If no shared option exists by build time, the map is drawn inside the spec, and the shared tool should gain the option (Page shapes, "New tools needed" 6).
4. **Georgetown County lot size.** The county's TotalLandArea field reads 1.0 on most parcels. Any sibling that used it for lot size (the Pawleys Island and Murrells Inlet pages?) should use Shape__Area / 43,560 instead.
