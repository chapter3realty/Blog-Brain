- **Home**: a parcel with a land use code starting with 1 and a county building value above 0. Kind: condo = code 107 or 135 or "HPR" in the legal description; townhome = 109; house = 101, 102, 110, 126; "code100" = a lot still coded 100 that has a building value (new homes the county has not recoded; 13, all in Belle Harbor). Codes as read in the 2026-10-d ledgers (sell-home-value row 1, first-time-buyer row 1, verified), from samples; the county publishes no code table.

- **Main home**: assessed at the 4 percent ratio (AssessedProp / TaxableProp under 0.05), the Myrtle Beach ledger's method. **Tax bill outside SC**: OwnerState is not SC.
- **Deeds**: Horry County Register of Deeds, AcclaimWeb, DEED (001), recorded 2025-10-01 to 2026-09-30, the reused file `data/2026-10-d/sell-out-of-state-buyers/out-of-state-buyers.json` (13,194 home sales; filters in its ledger row 1, verified).
